# Система управления учебными задачами студентов

Лабораторная работа №2 по дисциплине «Управление ИТ-проектами».

## Цель проекта
Разработать простую систему, в которой студент может создавать учебные задачи, указывать срок и приоритет, менять статус и отслеживать выполнение.

## Проектная модель
Для учебного проекта рассматриваются модели Waterfall, Agile и гибридная модель. Обоснование выбора приведено в ADR-001.

## Рабочее пространство
- GitHub Repository — исходные материалы проекта.
- GitHub Issues — задачи проекта.
- GitHub Projects — планирование и визуализация работы.
- Wiki — описание проекта, процесса и решений.

## Командные соглашения
- Ветка: `feat/ABC-12-short-name`
- Коммиты: `feat:`, `fix:`, `docs:`
- Одна ветка на задачу.
- Максимальная длительность работы по одной задаче — 3 дня.

## Статусы
Backlog → Ready → In progress → Review → Blocked → Done
