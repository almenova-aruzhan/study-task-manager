# О проекте

**Название:** Система управления учебными задачами студентов.

Система предназначена для учёта учебных задач. Пользователь может создавать задачи, указывать срок и приоритет, менять статус и просматривать список задач.

**Цель:** упростить планирование учебной работы и контроль выполнения задач.

**Сквозной проект:** используется как собственный проект команды для выбора модели поставки и оформления ADR-001.
