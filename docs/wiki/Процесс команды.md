# Процесс команды

1. Задача создаётся как Issue.
2. Задаче назначается статус и ответственный.
3. Для реализации создаётся отдельная ветка.
4. Формат ветки: feat/ABC-12-short-name.
5. Коммиты используют префиксы feat:, fix:, docs:.
6. Одна ветка соответствует одной задаче.
7. Работа по одной задаче не должна длиться более трёх дней.
8. После выполнения результат проверяется перед переводом в Done.
