# Рабочее пространство проекта

## Основные элементы
1. Repository — документы и материалы проекта.
2. Issues — отдельные задачи.
3. Projects — доска управления задачами.
4. Wiki — описание проекта и журнал решений.

## Поля Projects
- Size: S / M / L
- Owner
- Iteration
- Risk ID

## Статусы
- Backlog
- Ready
- In progress
- Review
- Blocked
- Done

## Правила
- Одна задача — одна ветка.
- Название ветки: feat/ABC-12-short-name.
- Коммит начинается с feat:, fix: или docs:.
- Работа по одной задаче не должна длиться более 3 дней.
