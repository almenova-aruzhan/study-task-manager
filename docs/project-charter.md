# Устав проекта — ЛЗ 3

| Элемент | Содержание |
|---|---|
| Название | Система управления учебными задачами студентов |
| Цель | Создать простой цифровой инструмент для хранения, планирования и контроля учебных задач |
| Заказчик / спонсор | Учебное допущение: Аружан Алменова как инициатор и лицо, принимающее решения в рамках учебного проекта |
| Проблема | Разрозненное хранение задач и ручной контроль сроков |
| Входит | Создание, редактирование и удаление задач; срок; приоритет; статус; список; фильтрация; документация |
| Не входит | Интеграция с университетской ИС, автоматическая выдача заданий преподавателями, платежи, сложная аналитика, промышленная эксплуатация |
| Допущения | 100 студентов; 15 мин/день ручного контроля; 2 000 ₸/час; снижение времени на 50%; горизонт 3 года |
| Ограничения | Учебный проект, ограниченные ресурсы, отсутствие реальных коммерческих цен и производственного заказчика |
| Критерии успеха | Рабочий MVP; 7,5 мин/день целевого времени; TCO ≤ 1,45 млн ₸ за 3 года в базовом сценарии; артефакты доступны в репозитории |
| Вехи | ЛЗ 3 — бизнес-кейс; ЛЗ 4 — требования; ЛЗ 5 — план; ЛЗ 7 — риски; ЛЗ 10 — CI/CD; ЛЗ 15 — портфолио |
| Полномочия PM | Управление учебным скоупом, порядком работ, решениями и бэклогом |
| Порог эскалации | Рост TCO >20%, срыв ключевой вехи >7 дней или изменение цели проекта |
